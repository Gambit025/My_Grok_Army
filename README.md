# Grok Office

Grok Office 是 Gambit 的 Grok Bot 小队看板：把 Rdog、内容组和交易组的工作状态投到一个 3D 办公室里，谁在干活、谁在等确认、用量分到哪只机器人，打开页面就能看到。这里只放看板相关的说明和源码备份，不包含私人频道地址。

## 小队构成

- **Ops**：Rdog
- **Content**：发帖官、剪辑导演、Rthought主编
- **Markets**：盯盘哨兵、策略总管、天鹅猎手

## 这个仓库是什么

这里存放 Gambit 办公室看板的说明，也是这套配置的备份。正在使用的 3D 办公室页面不公开。私人频道地址就是密码，绝不能出现在本仓库、注释、示例或 git 历史里。

## 可视化来源

办公室画面由独立的 3D 办公室 / 壁纸项目渲染：[grokbot-wallpaper](https://github.com/Bodila51/grokbot-wallpaper)。公开看板在 [https://bodila51.github.io/grokbot-wallpaper/office/](https://bodila51.github.io/grokbot-wallpaper/office/)，链接不含任何频道片段。该项目与 Grok Bot 的制作者没有隶属关系。本仓库不引入、也不复制它的源码。

## 安全

不要公开或提交私人办公室链接。那个链接就是密码。
